# Container Number Test Data

Shipping container numbers with a correctly computed ISO 6346 check digit. Owner codes are synthetic.

Free to use under **CC0-1.0** (public domain dedication, no attribution required).

## Files

- `container-small.json`
- `container-small.csv`
- `container-medium.json`
- `container-medium.csv`
- `container-large.json`
- `container-large.csv`

Each size ships as JSON and CSV. The data is deterministic: the same size always
produces the same rows.

## Source

Generated by StanzaAPI from <https://stanzaapi.com/datasets/container>.
